线性混合效应模型

基本介绍

混合效应模型主要用来对分组数据（按照一个或多个分类因子分组）进行统计建模。通过将相同的随机效应分配给共享同一分类因子水平的观测值，混合效应模型能够灵活地呈现由数据分组所导致的协方差结构。

例子：Rail

需要估算的量：

  1. “典型”钢轨的平均行程时间（期望行程时间）
  2. 不同钢轨之间平均行程时间的差异（钢轨间的变异性）
  3. 单根钢轨多次观测到的行程时间的差异（钢轨内的变异性）

最简单的模型

忽略分组结构，最简单的模型： \[ y_{ij} = \beta + \varepsilon_{ij},\;i = 1,\dots,M, \;j = 1,\dots,n_i\\ \varepsilon_{ij} \sim N(0, \sigma^2) \]

固定效应模型

固定效应模型

该固定效应模型的缺点在于：

  1. 它仅针对实验所用的特定钢轨样本，而不是这些样本所来源的钢轨总体
  2. 无法估计钢轨间的变异程度
  3. 参数数量会随钢轨数量的增加而线性增长

随机效应模型

随机效应模型将钢轨效应视为围绕总体均值的随机变异： \[ y_{ij} = \beta + b_i + \varepsilon_{ij},\;i = 1,\dots,M, \;j = 1,\dots,n_i\\ b_i \sim N(0, \sigma_b^2), \; \varepsilon_{ij} \sim N(0, \sigma^2) \]

\(\beta\) 代表所抽样钢轨总体的平均通过时间。

\(b_i\) 是表示第 \(i\) 根钢轨平均通过时间与总体均值偏离的随机变量，反映钢轨间的变异程度（between-rail variability）。

\(\varepsilon_{ij}\) 则表示第 \(i\) 根钢轨上第 \(j\) 次观测通过时间与该钢轨平均通过时间偏离的随机变量，反映钢轨内的变异程度（within-rail variability）。

随机效应模型

\(b_i\) 被称为随机效应，因为它们与从目标总体中随机选取的特定实验单元（本例中的钢轨）相关联，“效应”体现在它们代表了与总体均值的偏离。选择第 \(i\) 根钢轨的“效应”会使平均通过时间从 \(\beta\) 偏移至 \(\beta + b_i\)。

由于同一钢轨上的观测共享相同的随机效应 \(b_i\)，这些观测值之间具有相关性。同一钢轨上观测值之间的协方差为 \(\sigma_b^2\)，对应的相关系数为 \(\sigma_b^2 / (\sigma_b^2 + \sigma^2)\)。

构建的统计模型，其参数包括 \(\beta\)、\(\sigma_b^2\) 和 \(\sigma^2\)。

随机效应模型

需特别注意的是，无论实验中包含多少钢轨，模型参数的数量始终固定。虽然随机效应 \(b_i\) 在表现上类似于参数，但严格来说它们只是模型中另一层级的随机变量，因此并不直接对其进行“估计”。不过，仍会通过预测的方法来推断这些随机效应的取值。

AIC 和 BIC

AIC（Akaike Information Criterion）和 BIC（Bayesian Information Criterion）： \[ AIC = -2\log Lik + 2n_{par} \\ BIC = -2\log Lik + 2n_{par}\log(N) \]

Smaller is better.
