Section A：一般线性 F 检验

第一题解答

1. 原假设与备择假设

研究问题：在已经控制 hp 后，wt 和 disp 是否还能整体提升解释力？

  • 原假设 \(H_0\): \(\beta_{\text{wt}} = \beta_{\text{disp}} = 0\)（这两个变量对 mpg 没有额外贡献）
  • 备择假设 \(H_A\): 至少有一个不为 0（至少有一个变量有贡献）

2. 简化模型与完整模型

  • 简化模型（Reduced Model）\(M_R\): mpg ~ hp
  • 完整模型（Full Model）\(M_F\): mpg ~ hp + wt + disp

3. 手动计算 F 统计量与 p 值

首先提取两个模型的残差平方和：

sse_reduced <- sum(resid(mtcars_lm_hp)^2)
sse_full <- sum(resid(mtcars_lm_full)^2)

c(SSE_reduced = sse_reduced, SSE_full = sse_full)
SSE_reduced    SSE_full 
   447.6743    194.9907

计算 F 统计量： \[ F = \frac{\bigl[\mathrm{SSE}(M_R) - \mathrm{SSE}(M_F)\bigr] / q} {\mathrm{SSE}(M_F) / (n - p_F - 1)} \]

  • \(q = 2\)（约束个数，即被检验的参数个数）
  • \(n = 32\)（样本量）
  • \(p_F = 3\)（完整模型中解释变量的个数）
q <- 2
n <- 32
p_F <- 3

f_stat_manual <- (sse_reduced - sse_full) / q / (sse_full / (n - p_F - 1))
f_stat_manual
[1] 18.14226

使用 pf() 计算 p 值：

p_value_manual <- 1 - pf(f_stat_manual, df1 = q, df2 = n - p_F - 1)
p_value_manual
[1] 8.845519e-06

4. 使用 anova() 验证

anova(mtcars_lm_hp, mtcars_lm_full)
# A tibble: 2 × 6
  Res.Df   RSS    Df `Sum of Sq`     F    `Pr(>F)`
   <dbl> <dbl> <dbl>       <dbl> <dbl>       <dbl>
1     30  448.    NA         NA   NA   NA         
2     28  195.     2        253.  18.1  0.00000885

结果完全一致。

5. 结论

由于 p 值 << 0.05，我们拒绝原假设。结论：在控制 hp 后，wt 和 disp 作为一个变量组能显著提升对 mpg 的解释力。

Section B：\(R^2\)、调整 \(R^2\) 与部分 \(R^2\)

第二题解答

1. 手动计算 \(R^2\) 和调整 \(R^2\)

首先计算总平方和 SST：

y <- mtcars_df$mpg
y_bar <- mean(y)
sst <- sum((y - y_bar)^2)
sst
[1] 1126.047

计算 \(R^2\)：

\[ R^2 = 1 - \frac{\text{SSE}}{\text{SST}} \]

r_squared_manual <- 1 - sse_full / sst
r_squared_manual
[1] 0.8268361

计算调整 \(R^2\)：

\[ {R}_{\text{adj}}^2 = 1 - \frac{\mathrm{SSE}/(n-p-1)}{\mathrm{SST}/(n-1)} \]

n <- 32
p <- 3
adj_r_squared_manual <- 1 - (sse_full / (n - p - 1)) / (sst / (n - 1))
adj_r_squared_manual
[1] 0.8082829

与 summary() 结果验证：

c(R2_manual = r_squared_manual, R2_builtin = summary(mtcars_lm_full)$r.squared)
 R2_manual R2_builtin 
 0.8268361  0.8268361 
c(AdjR2_manual = adj_r_squared_manual, AdjR2_builtin = summary(mtcars_lm_full)$adj.r.squared)
 AdjR2_manual AdjR2_builtin 
    0.8082829     0.8082829

2. 计算部分 \(R^2\)

\[ R^2_{\text{partial}} = \frac{\text{SSE}(M_R) - \text{SSE}(M_F)}{\text{SSE}(M_R)} \]

partial_r_squared <- (sse_reduced - sse_full) / sse_reduced
partial_r_squared
[1] 0.5644363

3. 部分 \(R^2\) 的实际含义

部分 \(R^2\) = 0.56 表示：在 hp 尚未解释掉的那部分变异中，wt 和 disp 又额外解释了约 56%。也就是说，即使 hp 已经进入模型，wt 和 disp 还能再解释超过一半的剩余残差变异，说明这两个变量作为一个整体提供了有价值的额外信息。

Section C：多重共线性诊断

第三题解答

1. 定义 vif_man() 函数并验证

vif_man <- function(model) {
  # 提取模型矩阵（不包括截距项）
  x <- model.matrix(model)[, -1]
  
  # 初始化 VIF 向量
  vif_values <- numeric(ncol(x))
  
  # 循环计算每个预测变量的 VIF
  for (j in seq_along(vif_values)) {
    # 当前预测变量
    x_j <- x[, j]
    
    # 其他预测变量
    x_other <- x[, -j, drop = FALSE]
    
    # 拟合回归模型：x_j ~ x_other
    fit <- lm(x_j ~ ., data = as.data.frame(x_other))
    
    # 提取 R^2
    r_squared_j <- summary(fit)$r.squared
    
    # 计算 VIF
    vif_values[j] <- 1 / (1 - r_squared_j)
  }
  
  names(vif_values) <- colnames(x)
  return(vif_values)
}

比较手动计算与 car::vif() 的结果：

vif_manual <- vif_man(mtcars_lm_full)
vif_builtin <- vif(mtcars_lm_full)

2. VIF 判断

从结果可以看到，所有 VIF 值都小于 10，根据经验法则：不存在严重的多重共线性问题。
