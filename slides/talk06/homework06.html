Part 1：嵌套模型比较与顺序平方和

回顾：三个模型

对于任意一个线性模型，都可以通过残差平方和衡量“模型还没解释掉多少变异”：

\[ \mathrm{SSE} = \sum_{i = 1}^{n} (y_i - \hat{y}_i)^2 \]

下面先提取几个模型的残差平方和：

sse_hp <- sum(resid(mtcars_lm_hp)^2)
sse_hp_wt <- sum(resid(mtcars_lm_hp_wt)^2)
sse_full <- sum(resid(mtcars_lm_full)^2)

c(
  sse_hp = sse_hp,
  sse_hp_wt = sse_hp_wt,
  sse_full = sse_full
)
   sse_hp sse_hp_wt  sse_full 
 447.6743  195.0478  194.9907

顺序平方和的两个等价定义

对于已有变量组 \(A\) 和新加入的变量组 \(B\)，顺序平方和可以写为

\[ \mathrm{SSR}(B \mid A) = \mathrm{SSE}(A) - \mathrm{SSE}(A, B) \]

也可以写为

\[ \mathrm{SSR}(B \mid A) = \sum_{i=1}^n \left(\hat{y}_{i, A,B} - \hat{y}_{i, A}\right)^2 \]

这两个公式一个从“残差平方和减少了多少”出发，另一个从“拟合值多解释了多少变异”出发。它们在理论上是等价的。

下面先看一个具体例子：在已经有 hp 的基础上，再加入变量组 wt + disp。

ssr_group_from_sse <- sse_hp - sse_full

yhat_hp <- fitted(mtcars_lm_hp)
yhat_full <- fitted(mtcars_lm_full)

ssr_group_from_fitted <- sum((yhat_full - yhat_hp)^2)

对单个 lm 对象使用 anova() 时，输出的是按变量进入顺序得到的顺序平方和（Type I sum of squares）。

在模型

\[ \texttt{mpg} \sim \texttt{hp} + \texttt{wt} + \texttt{disp} \]

中：

  • hp 这一行衡量的是 hp 在最先进入模型时解释了多少变异；
  • wt 这一行衡量的是 wt 在 hp 已经进入后又额外解释了多少变异；
  • disp 这一行衡量的是 disp 在 hp 和 wt 已经进入后又额外解释了多少变异。

因此，这个表的结果会受到变量顺序影响。

drop1() 的思路

drop1(mtcars_lm_full, test = "F")
# A tibble: 4 × 6
     Df `Sum of Sq`   RSS   AIC `F value` `Pr(>F)`
  <dbl>       <dbl> <dbl> <dbl>     <dbl>    <dbl>
1    NA     NA       195.  65.8  NA       NA      
2     1     51.7     247.  71.4   7.42     0.0110 
3     1     88.5     283.  75.8  12.7      0.00133
4     1      0.0571  195.  63.8   0.00820  0.929

drop1() 从完整模型出发，每次删除一个变量，并把删去后的模型与完整模型进行比较。因此它回答的是：

在其他变量已经保留在模型中的前提下，删去某一个变量是否会显著恶化模型拟合？

所以，drop1(..., test = "F") 给出的更接近“控制其他变量后的单个变量检验”，与系数 t 检验在一自由度下是对应的。

回顾 VIF 的定义

对第 \(j\) 个解释变量，如果把它当作响应变量、其余解释变量当作自变量做一个辅助回归，并记该辅助回归的决定系数为 \(R_j^2\)，那么

\[ \mathrm{VIF}_j = \frac{1}{1 - R_j^2} \]

例如，要计算 hp 的 VIF，就可以拟合辅助回归：

\[ \texttt{hp} = \gamma_0 + \gamma_1 \texttt{wt} + \gamma_2 \texttt{disp} + e \]

hp_aux_lm <- lm(hp ~ wt + disp, data = mtcars_df)
summary(hp_aux_lm)$r.squared
[1] 0.6345874
1 / (1 - summary(hp_aux_lm)$r.squared)
[1] 2.736633

自定义函数 vif_man

下面给出一个函数框架。你可以先理解其思路，再补充或重写。

vif_man <- function(model) {
  model_matrix <- model.matrix(model)[, -1, drop = FALSE]
  predictor_names <- colnames(model_matrix)

  vif_values <-
    map_dbl(
      predictor_names,
      function(var_name) {
        y_aux <- model_matrix[, var_name]
        x_aux <- model_matrix[, setdiff(predictor_names, var_name), drop = FALSE]

        aux_df <- as_tibble(x_aux) |>
          mutate(y_aux = y_aux)

        aux_formula <-
          reformulate(
            termlabels = setdiff(predictor_names, var_name),
            response = "y_aux"
          )

        aux_lm <- lm(aux_formula, data = aux_df)
        r_squared_aux <- summary(aux_lm)$r.squared
        1 / (1 - r_squared_aux)
      }
    )

  names(vif_values) <- predictor_names
  vif_values
}
