数据整理(Data tidying)

“幸福的家庭都是相似的，不幸的家庭各有各的不幸。”
— 列夫·托尔斯泰

“Tidy datasets are all alike, but every messy dataset is messy in its own way.”
— Hadley Wickham

什么是tidy data?

  1. 每个变量一列，每列一个变量
  2. 每个观测一行，每行一个观测
  3. 每个值一个单元格，每个单元格一个值 来源：R4DS by Hadley Wickham

tidyr包

tidyr包提供了一系列函数用于数据整理，核心函数包括：

  • pivot_longer()：宽数据转长数据
  • pivot_wider()：长数据转宽数据
  • separate()：拆分列
  • unite()：合并列
  • drop_na()：删除缺失值
  • replace_na()：替换缺失值
  • …

pivot_longer()的作用方式

宽格式

df <- tribble(
  ~id,  ~bp1, ~bp2,
   "A",  100,  120,
   "B",  140,  115,
   "C",  120,  125
)
df

  id      bp1   bp2
  <chr> <dbl> <dbl>
1 A       100   120
2 B       140   115

df |> 
  pivot_longer(
    cols = bp1:bp2,
    names_to = "measurement",
    values_to = "value"

readr包

readr包提供了一系列函数用于数据读写，核心函数包括：

  • read_csv()：读取CSV文件
  • read_tsv()：读取制表符分隔的文件
  • read_delim()：读取任意分隔符的文件
  • read_table()：读取空格分隔的文件
  • write_csv()：写入CSV文件
  • write_rds()：写入RDS文件
  • …

总结：线性模型

前述的统计方法（t检验、ANOVA、相关分析等）都可以看作是线性模型（linear model）的特例，基本形式为： \[ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + ... + \beta_p X_p + \epsilon \] 其中，\(Y\)是响应变量，\(X_1, X_2, ..., X_p\)是解释变量，\(\beta_0\)是截距，\(\beta_1, \beta_2, ..., \beta_p\)是回归系数，\(\epsilon\)是误差项。

线性回归的基本假设

线性回归模型的基本假设包括：

  1. 线性关系：响应变量与解释变量之间存在线性关系。
  2. 独立性：观测值之间相互独立。
  3. 同方差性：误差项的方差在所有水平上是相同的。
  4. 正态性：误差项服从正态分布。
  5. 无多重共线性：解释变量之间不存在高度相关性。

一元线性回归

对于如下数据： \[ \begin{matrix} y_1 & x_1 \\ y_2 & x_2 \\ \dots &\dots \\ y_n & x_n \end{matrix} \] 一元线性回归形式如下： \[ y_i = \beta_0 + \beta_1 x_{i}+ \varepsilon_i\qquad i=1,\dots,n \]

一元线性回归：独立与同方差性假设

\[ y_i = \beta_0 + \beta_1 x_{i}+ \varepsilon_i\qquad i=1,\dots,n \]

对于误差项\(\varepsilon_i\)，通常假设为独立同分布的随机变量，满足： \[ E(\varepsilon_i) = 0 \\ Cov(\varepsilon_i,\varepsilon_j) = \begin{cases} \sigma^2, & i = j \\ 0, & i \neq j \end{cases} \qquad i, j = 1, \dots, n \]

这个假定常称为高斯-马尔可夫假定（Gauss-Markov assumptions）。

一元线性回归：正态性假设

为了方便对参数做区间估计和假设检验，通常还会假设误差项\(\varepsilon_i\)服从正态分布，即： \[ \varepsilon_i \sim N(0, \sigma^2) \qquad i=1,\dots,n \]

在此假定下，进一步随机变量\(y_i\)也服从正态分布： \[ y_i \sim N(\beta_0 + \beta_1 x_i, \sigma^2) \qquad i=1,\dots,n \]

一元线性回归：矩阵形式

对于\(n\)个观测值一元线性回归模型。令：

\[ \mathbf{y} = \begin{bmatrix}y_1 \\ y_2 \\ \vdots \\ y_n\end{bmatrix}, \quad \mathbf{X} = \begin{bmatrix}1 & x_1 \\ 1 & x_2 \\ \vdots & \vdots \\ 1 & x_n\end{bmatrix}, \quad \mathbf{\varepsilon} = \begin{bmatrix}\varepsilon_1 \\ \varepsilon_2 \\ \vdots \\ \varepsilon_n\end{bmatrix}, \quad \mathbf{\beta} = \begin{bmatrix}\beta_0 \\ \beta_1\end{bmatrix} \] 模型可以表示为： \[ \mathbf{y} = \mathbf{X}\mathbf{\beta} + \mathbf{\varepsilon}\\ E(\mathbf{\varepsilon}) = \mathbf{0} \\ Cov(\mathbf{\varepsilon}) = \sigma^2 \mathbf{I} \]

参数估计：普通最小二乘法

  • 回归分析的主要任务

通过n组样本观测值\(\{(x_i, y_i)\}_{i=1}^n\)对\(\beta_0\)和\(\beta_1\)进行估计，一般用\(\widehat{\beta_0}\)和\(\widehat{\beta_1}\)表示\(\beta_0\)和\(\beta_1\)的估计值

  • 普通最小二乘法（Ordinary Least Squares, OLS）

对于每一个观测值\((x_i, y_i)\)，最小二乘法考虑观测值与其回归值的离差越小越好，综合考虑n个离差值，定义离差平方和为： \[ \begin{align*} Q(\beta_0,\beta_1) &= \sum_{i=1}^n (y_i - E(y_i))^2 \\ &= \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 \end{align*} \] 最小二乘法的核心思想是寻找\(\beta_0\)和\(\beta_1\)的估计值\(\widehat{\beta_0}\)和\(\widehat{\beta_1}\)使离差平方和最小： \[ \begin{align*} Q(\beta_0,\beta_1) &=\sum_{i=1}^n (y_i - (\widehat{\beta_0} + \widehat{\beta_1} x_i))^2 \\ &= \min_{\beta_0, \beta_1} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 \end{align*} \]

普通最小二乘法：图示

如何得到最小二乘估计？

这是一个求极值的问题 \[ \begin{align*} Q(\beta_0,\beta_1) &=\sum_{i=1}^n (y_i - (\widehat{\beta_0} + \widehat{\beta_1} x_i))^2 \\ &= \min_{\beta_0, \beta_1} \sum_{i=1}^n (y_i - (\beta_0 + \beta_1 x_i))^2 \end{align*} \] \(\widehat{\beta_0}\)和\(\widehat{\beta_1}\)应该满足： \[ \frac{\partial Q}{\partial \beta_0}\Big|_{\beta_0 = \widehat{\beta_0}} = -2\sum_{i=1}^n (y_i - (\widehat{\beta_0} + \widehat{\beta_1} x_i)) = 0 \\ \frac{\partial Q}{\partial \beta_1}\Big|_{\beta_1 = \widehat{\beta_1}} = -2\sum_{i=1}^n x_i (y_i - (\widehat{\beta_0} + \widehat{\beta_1} x_i)) = 0 \] 求解可得： \[ \widehat{\beta_1} = \frac{\sum_{i=1}^n (x_i - \overline{x})(y_i - \overline{y})}{\sum_{i=1}^n (x_i - \overline{x})^2} \\ \widehat{\beta_0} = \overline{y} - \widehat{\beta_1} \overline{x} \] 这里\(\overline{x}=\frac{1}{n}\sum_{i=1}^n x_i\)，\(\overline{y}=\frac{1}{n}\sum_{i=1}^n y_i\)。

Note

由\(\hat{\beta_0} = \overline{y} - \hat{\beta_1} \overline{x}\)可知回归直线是通过点\((\overline{x}, \overline{y})\)的。

残差

当求出\(\widehat{\beta_0}\)和\(\widehat{\beta_1}\)的最小二乘估计后，称： \[ \widehat{y}_i = \widehat{\beta_0} + \widehat{\beta_1} x_i \] 为观测值\(y_i\)的回归拟合值，称： \[ e_i = y_i - \widehat{y}_i \] 为\(y_i\)的残差（residual）。另，残差有如下性质： \[ \sum_{i=1}^n e_i = 0 \\ \sum_{i=1}^n x_i e_i = 0 \]

最小二乘估计的性质：线性

由于： \[ \begin{align*} \quad \widehat{\beta_1} &= \frac{\sum_{i=1}^n (x_i - \overline{x})(y_i - \overline{y})}{\sum_{i=1}^n (x_i - \overline{x})^2} \\ &= \frac{\sum_{i=1}^n (x_i - \overline{x})y_i}{\sum_{i=1}^n (x_i - \overline{x})^2} \\ & = \sum_{i=1}^n \frac{x_i - \overline{x}}{\sum_{j=1}^n (x_j - \overline{x})^2}y_i \end{align*} \] 所以\(\hat{\beta_1}\)是\(y_i\)的线性组合。同理可得\(\hat{\beta_0}\)也是\(y_i\)的线性组合。

最小二乘估计的性质：无偏性

\(x_i\)非随机变量，\(y_i = \beta_0 + \beta_1x_i + \varepsilon_i\)，其中\(E(\varepsilon_i) = 0\)，固： \[ E(y_i) = \beta_0 + \beta_1 x_i \] 又\(\hat{\beta_1}\)是\(y_i\)的线性组合： \[ E(\widehat{\beta_1}) = \sum_{i=1}^n \frac{x_i - \overline{x}}{\sum_{j=1}^n (x_j - \overline{x})^2}E(y_i) = \sum_{i=1}^n \frac{x_i - \overline{x}}{\sum_{j=1}^n (x_j - \overline{x})^2}(\beta_0 + \beta_1 x_i) \] 利用\(\sum(x-\overline{x}) = 0\)和\(\sum(x_i-\overline{x})x_i = \sum(x_i-\overline{x})^2\)可得 \[ E(\widehat{\beta_1}) = \beta_1 \] 即\(\hat{\beta_1}\)是\(\beta_1\)的无偏估计。同理可得\(\hat{\beta_0}\)也是\(\beta_0\)的无偏估计。

Note

无偏估计的意义是，如果重复进行抽样和估计，估计值（\(\hat{\beta_0}\)和\(\hat{\beta_1}\)）的平均将趋近于参数的真实值（\(\beta_0\)和\(\beta_1\)）。

进一步有： \[ E(\hat{y}) = E(\widehat{\beta_0} + \widehat{\beta_1} x) = \beta_0 + \beta_1 x = E(y) \] 即回归拟合值\(\widehat{y}\)也是\(y\)的无偏估计。

\(\hat{\beta_0}\)和\(\hat{\beta_1}\)的方差

由\(y_1,y2,\dots,y_n\)相互独立，且\(Var(y_i) = \sigma^2\)，可得： \[ var(\widehat{\beta_1}) = \frac{\sigma^2}{\sum_{i=1}^n (x_i - \overline{x})^2} \\ var(\widehat{\beta_0}) = \sigma^2 \left( \frac{1}{n} + \frac{\overline{x}^2}{\sum_{i=1}^n (x_i - \overline{x})^2} \right) \]

Note

回归常/系数估算值的波动范围不仅与随机误差的方差\(\sigma^2\)有关：
1. 还与自变量\(x_i\)取值的离散程度有关。如果\(x\)的取值比较分散，则\(\hat{\beta}\)的方差较小，估计值更稳定；反之，如果\(x\)的取值比较集中，则\(\hat{\beta}\)的方差较大，估计值的稳定性就差。
2. \(\hat{\beta_0}\)的方差还与样本量\(n\)有关，\(n\)越大，\(\hat{\beta_0}\)的方差越小，估计值越稳定。

\(\hat{\beta_0}\)和\(\hat{\beta_1}\)的分布

\(\hat{\beta_0}\)和\(\hat{\beta_1}\)是\(n\)个独立正态随机变量\(y_1,y_2,\dots,y_n\)的线性组合，所以它们也服从正态分布： \[ \widehat{\beta_1} \sim N\left(\beta_1, \frac{\sigma^2}{\sum_{i=1}^n (x_i - \overline{x})^2}\right) \\ \widehat{\beta_0} \sim N\left(\beta_0, \sigma^2 \left( \frac{1}{n} + \frac{\overline{x}^2}{\sum_{i=1}^n (x_i - \overline{x})^2} \right)\right) \] 另外，\(\hat{\beta_0}\)和\(\hat{\beta_1}\)之间的协方差为： \[ cov(\widehat{\beta_0}, \widehat{\beta_1}) = -\frac{\overline{x}\sigma^2}{\sum_{i=1}^n (x_i - \overline{x})^2} \] 所以：

Note

  1. 在\(\overline{x} = 0\)时，\(\hat{\beta_0}\)和\(\hat{\beta_1}\)不相关。
  2. 在\(\overline{x} \neq 0\)时，\(\hat{\beta_0}\)和\(\hat{\beta_1}\)相关，不独立。

最小二乘估计的性质：BLUE

Note

在满足高斯-马尔可夫假定的前提下，最小二乘估计是线性无偏估计中方差最小的估计，即最佳线性无偏估计BLUE（Best Linear Unbiased Estimator）。

对于固定\(x_0\): \[ \hat{y_0} = \widehat{\beta_0} + \widehat{\beta_1} x_0 \] 也是\(y_1, y_2, \dots, y_n\)的线性组合，且： \[ \hat{y_0} \sim N\left(\beta_0 + \beta_1 x_0, \sigma^2 \left(\frac{1}{n} + \frac{(x_0 - \overline{x})^2}{\sum_{i=1}^n (x_i - \overline{x})^2} \right)\right) \]

Note

\(\hat{y_0}\)是\(E(y_0)\)的无偏估计,且\(\hat{y_0}\)的方差随给定的\(x_0\)与\(\overline{x}\)的距离的增大而增大。

模型拟合优度：\(R^2\)和\(Adjusted\;R^2\)

SSR（回归平方和）和SSE（残差平方和）的计算公式如下： \[ SSR = \sum(\widehat{y}_i - \overline{y}) ^2\\ SSE = \sum(y_i - \widehat{y}_i) ^2 \]

决定系数（\(R^2\)）是常用的衡量模型拟合优度的指标，计算公式为： \[ R^2=1 - \frac{\sum{(y_i - \widehat{y}_i)^2}}{\sum{(y_i - \overline{y} )^2}} \]

注意: \(R^2\)可能随着解释变量数量的增加而增加，即使新增的变量并未真正提高模型的预测能力。

\(Adjusted\;R^2\)

\(Adjusted\;R^2\)对\(R^2\)进行了调整，考虑了模型中解释变量的数量，避免了由于模型中增加不必要的变量而导致\(R^2\)提高的问题。其计算公式为： \[ R_{adj}^2 = 1 - (1-R^2)\frac{n-1}{n-p-1} \]
