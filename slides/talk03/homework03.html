3 常用 Markdown 语法与示例

通过前次作业，你应该已经对 Quarto 有了初步了解，这次作业将继续练习 Markdown 的基础用法，特别是一些常用的文本格式和结构。

  • 粗体与斜体：

    • 粗体：**加粗内容** → 加粗内容
    • 斜体：*斜体内容* → 斜体内容
    • 粗体+斜体：***加粗且斜体内容*** → 加粗且斜体内容

  • 插入图片：

    ![图片说明](图片路径)

  • 插入链接：

    [链接文字](链接地址)

  • 表格：

  | 姓名 | 分数 |
  | ---- | ----|
  | 张三 | 90   |
  | 李四 | 85   |
姓名 分数
张三 90
李四 85
