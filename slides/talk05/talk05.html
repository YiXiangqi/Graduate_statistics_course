一元线性回归：独立与同方差性假设

\[ y_i = \beta_0 + \beta_1 x_{i}+ \varepsilon_i\qquad i=1,\dots,n \]

对于误差项\(\varepsilon_i\)，通常假设为独立同分布的随机变量，满足： \[ E(\varepsilon_i) = 0 \\ Cov(\varepsilon_i,\varepsilon_j) = \begin{cases} \sigma^2, & i = j \\ 0, & i \neq j \end{cases} \qquad i, j = 1, \dots, n \]

这个假定常称为高斯-马尔可夫假定（Gauss-Markov assumptions）。

但实际问题中，可能存在： \[ Cov(\varepsilon_i,\varepsilon_j) \neq 0 \quad \text{for some } i \neq j \]

即存误差项之间存在相关性。

复习：独立性假定

线性模型：

y = X+ , E()=0, Var()=^2 I

若 Cov() ^2 I，OLS 仍一致但标准误不再可靠。

影响（直观）

  • 错误的标准误 -> 错误的 p 值
  • 预测与区间估计受影响

诊断工作流程（简要）

  1. 可视化残差（随时间或空间）
  2. 时序：ACF / PACF / Durbin–Watson / Ljung–Box
  3. 空间：经验变差函数（variogram）/ Moran’s I
  4. 根据结果选择模型或稳健 SE
