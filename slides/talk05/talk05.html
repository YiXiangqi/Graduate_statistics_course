回顾：线性回归的基本假设

线性回归模型的基本假设包括

  1. 线性关系：响应变量与解释变量之间存在线性关系。
  2. 独立性：观测值之间相互独立。
  3. 同方差性：误差项的方差在所有水平上是相同的。
  4. 正态性：误差项服从正态分布。
  5. 无多重共线性(多元线性回归)：解释变量之间不存在高度相关性。

误差项间的相关性

一元线性回归：独立与同方差性假设

\[ y_i = \beta_0 + \beta_1 x_{i}+ \varepsilon_i\qquad i=1,\dots,n \]

对于误差项\(\varepsilon_i\)，通常假设为独立同分布的随机变量，满足： \[ E(\varepsilon_i) = 0 \\ Cov(\varepsilon_i,\varepsilon_j) = \begin{cases} \sigma^2, & i = j \\ 0, & i \neq j \end{cases} \qquad i, j = 1, \dots, n \]

这个假定常称为高斯-马尔可夫假定（Gauss-Markov assumptions）。

但实际问题中，可能存在： \[ Cov(\varepsilon_i,\varepsilon_j) \neq 0, \quad \exists i \neq j \]

即存误差项之间存在相关性。

带来的问题

当线性模型的随机误差项存在相关性时，若仍直接用OLS做参数估计，可能会导致：

  • OLS估计量仍然是无偏的，但不再是最优的（不再是BLUE）。
  • 均方误差（MSE）可能严重低估误差项的方差。
  • t检验和F检验的结果不可靠，可能出现过度拒绝原假设的情况（即增加第一类错误率）。
  • OLS估计量对抽样波动非常敏感，即在任一特定样本中，\(\hat{\beta}\) 可能偏离真实值较远。

自相关产生的原因

  • 遗漏关键变量
  • 模型设定错误（如遗漏非线性关系）
  • 遗漏滞后项（时间序列） 。。。

残差自相关系数

计算时间滞后为 1 的残差自相关系数：

  • 计算公式
  • 代码

\[ r_1 = \frac{\sum_{i=2}^n (e_i - \bar{e})(e_{i-1} - \bar{e})}{\sum_{i=1}^n (e_i - \bar{e})^2} \]

两个随机变量的样本相关系数计算：

\[ r = \frac{\sum_{i=1}^n (x_i - \bar{x})(y_i - \bar{y})}{\sqrt{\sum_{i=1}^n (x_i - \bar{x})^2} \sqrt{\sum_{i=1}^n (y_i - \bar{y})^2}} \]

自相关的应对：使用correlation参数指定误差项的自相关结构

  • AR(1)模型
  • 代码

Hawaii：通过对残差的分析，显示误差项间存在自相关： \[ \varepsilon_i = \rho \varepsilon_{i-1} + \eta_i \] 其中\(\eta_i\)为白噪声误差项，\(\rho\)为自相关系数。

这种自相关结构称为阶数为 1 的自回归模型，AR(1)模型。

此时的误差项之间的协方差和相关系数分别为： \[ Cov(\varepsilon_i,\varepsilon_j) = \sigma^2 \rho^{|i-j|} \qquad i, j = 1, \dots, n \\ Cor(\varepsilon_i,\varepsilon_j) = \rho^{|i-j|} \qquad i, j = 1, \dots, n \]

nlme包中的gls()函数允许我们指定误差项的自相关结构：

Hawaii_gls_m1 <- 
  gls(Birds ~ Rainfall + Year, data = Hawaii, na.action = na.omit,
      correlation = corAR1(form = ~ Year))

另一种写法：

Hawaii_gls_m1 <- 
  update(Hawaii_gls_m0, correlation = corAR1(form = ~ Year))

误差项的相关结构

当误差项之间不满足独立性假设，通过引入函数\(h(.)\)来对不同时间点残差之间的自相关性进行建模：

\[ cor(\varepsilon_s, \varepsilon_t) = h(d(\mathbf{p_s}, \mathbf{p_t}), \mathbf{\rho}) \] 函数\(h(.)\)称为相关函数，其取值范围在 -1 到 1 之间，\(\rho\)是一个相关参数（correlation parameters）向量，\(p_s, p_t\)是位置向量（position vectors），\(d(p_s, p_t)\)表示两者间的距离。

isotropic correlation structure

假定相关结构（correlation structure）为各向同性（isotropic），即相关函数\(h(.)\)仅依赖于位置向量之间的距离，而与具体位置无关。

corComSymm()

  • 复合对称结构
  • 残差计算
  • 残差图
  • 模型比较

nlme包中提供了多种相关结构函数，最简单的序列相关结构是复合对称结构(compound symmetry structure)。它假设无论两个观测值之间的时间距离如何，它们的残差相关性都是相同的: \[ cor(\varepsilon_s, \varepsilon_t) = \rho, \quad\; \forall s \neq t \]

corARMA

ARMA模型（autoregressive-moving average correlation model）由两个参数定义其阶数：

  • 自回归参数的数量（p）
  • 移动平均参数的数量（q）。

ARMA(1, 0) 表示前述的AR(1)模型。ARMA(p, 0)结构由如下： \[ \varepsilon_s = \phi_1\varepsilon_{s-1} +\phi_2\varepsilon_{s-2} +\dots + \phi_p\varepsilon_{s-p} + \eta_s \]

ARMA(0, p) 的结构由如下： \[ \varepsilon_s = \theta_1\eta_{s-1} +\theta_2\eta_{s-2} +\dots + \theta_p\eta_{s-p} + \eta_s \]

ARMA(p, q) 由上面两个结构组合而成： \[ \varepsilon_s = \sum^p_{i=1}\phi_i\varepsilon_{s-i} + \sum^{q}_{j=i}\theta_j\eta_{s-j} + \eta_s \]

如何确认ARMA的p和q

Important

Citing from Schabenberger and Pierce (2002):

“In our experience it is more important to model the correlation structure in a reasonable and meaningful way rather than to model the correlation structure perfectly”.

partial autocorrelation function (pacf)

pacf 用于测量在控制了所有较短滞后阶数的自相关之后，特定滞后阶数的自相关程度。

acf()和pacf()来确定ARMA的p和q

acf pacf
AR(p) 逐渐衰减 在p阶截断
MA(q) 在q阶截断 逐渐衰减
ARMA(p, q) 逐渐衰减在max(0, q-p)阶之后 逐渐衰减在max(0, p-q)阶之后

变异函数（variogram）

变异函数，(semi-)variogram，是空间统计学中用于描述空间相关性的工具，表示空间数据中变量值之间的差异程度随空间距离的变化情况。 通常有如下定义： \[ \gamma(\mathbf{h}) = \frac{1}{2} Var[Z(\mathbf{x}) - Z(\mathbf{x} + \mathbf{h})] \] 其中\(h\)表示空间距离（lag distance），\(\mathbf{x}\)表示空间位置向量，\(Z(\mathbf{x})\)表示位置\(\mathbf{x}\)处的变量值。 变异函数需要假定 intrinsic stationarity： \[ E[Z(\mathbf{x}+\mathbf{h}) - Z(\mathbf{x})] = 0 \\ Var[Z(\mathbf{x}+\mathbf{h}) - Z(\mathbf{x})] = 2\gamma(\mathbf{h}) \] 这个假定确保变异函数只是位置之间距离的函数，而与具体位置无关，且不需要假定数据的均值是常数或者有限方差。

变异函数与协方差

如果进一步假定weak(second-order) stationarity： \[ E[Z(\mathbf{x})] = \mu \\ Cov(Z(\mathbf{x}), Z(\mathbf{x}+\mathbf{h})) = C(\mathbf{h}) \] 可以将变异函数表示为协方差函数的函数： \[ \gamma(\mathbf{h}) = C(0) - C(\mathbf{h}) \] 其中\(C(0)\)表示位置之间距离为0时的协方差，即变量的方差。

变异函数的估算

当我们假定 ergodicity 时, \(\gamma(\mathbf{h})\)的估计值：

\[ \hat{\gamma}(\mathbf{h}) = \frac{1}{2N(\mathbf{h})} \sum_{i = 1}^{N(\mathbf{h})} (Z(\mathbf{x_i}+\mathbf{h}) - Z(\mathbf{x_i}))^2 \] 其中\(N(\mathbf{h})\)表示距离为\(h\)的观测对的数量。

残差的变异函数图

在线性回归模型中，误差项满足的假设条件是比 intrinsic stationary 和 weak stationary 更严格的条件，因此残差的变异函数图可以用来诊断误差项的空间相关结构：

  • 代码
  • 图
Boreality_variogram_df <-
  Boreality |>
    mutate(resid = rstandard(Boreality_lm_m0)) |>
    select(resid, x, y)

coordinates(Boreality_variogram_df) <- ~x+y

Boreality_variogram <- variogram(resid ~ 1, Boreality_variogram_df)

当误差限之间不存在相关性时，残差的变异函数图应该近似为一个水平线。如果变异函数图显示出随距离增加而增加的趋势，或者存在明显的模式（如周期性），则表明误差项之间存在空间相关性。

各向同性

变异函数通常假定误差项的空间相关结构为各向同性（isotropic）。 通过绘制不同方向的variogram图，可以检查误差项的空间相关结构是否满足各向同性假设：

  • 代码
  • 图
Boreality_variogram_alpha <-
  variogram(
    resid ~ 1,
    Boreality_variogram_df,
    alpha = c(0, 45, 90, 135)
  ) |>
  plot()

空间相关结构

通过引入函数\(h(.)\)来对不同位置的误差项之间的空间相关性进行建模： \[ cor(\varepsilon_s, \varepsilon_t) = h(d(\mathbf{p_s}, \mathbf{p_t}), \mathbf{\rho}) \] 函数\(h(.)\)称为相关函数，其取值范围在 -1 到 1 之间，\(\rho\)是一个相关参数（correlation parameters）向量，\(p_s, p_t\)是位置向量（position vectors），\(d(p_s, p_t)\)表示两者间的距离。

nlme包中提供了多种相关结构函数:

  • corExp(): 指数相关结构
  • corGaus(): 高斯相关结构
  • corSpher(): 球面相关结构
  • corLin(): 线性相关结构 …
