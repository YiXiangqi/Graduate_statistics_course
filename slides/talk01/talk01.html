R语言基础

R语言是什么？

R是一种主要用于统计分析和数据可视化的编程语言和环境。

R语言的特点：

  • 开源：免费使用，拥有庞大的社区支持。
  • 专为统计分析设计：提供了丰富的统计方法和工具，适合各种数据分析任务。
  • 优秀的可视化功能：如ggplot2等包提供了强大的数据可视化工具。
  • 丰富的包：有成千上万的包，涵盖各种工具，例如，机器学习、深度学习、生物信息学等领域。

R语言的安装

R语言的安装包括R本身和一个集成开发环境（IDE）,推荐使用RStudio作为IDE。

  1. 安装R语言：
    • 访问R项目官网下载并安装适合你操作系统的R版本。
  2. 安装RStudio：
    • 访问RStudio官网下载并安装RStudio Desktop版本。

Positron是Posit公司全新推出的IDE，如果你熟悉vs code，想要更好的AI支持，可以考虑安装Positron。

对象

对象（object）：在R中，对象是数据的载体，可以是数值、字符、逻辑值、函数等。

赋值：要创建一个R对象，先确定一个名称，使用<-或=将数据赋值给它。

# 两种符号创建对象
x <- 10
x
[1] 10
y = 20
y
[1] 20

虽然<-和=都可以用于赋值，推荐使用<-，以避免与函数参数中的=混淆。

对象命名规则

  • 对象名以字母或点（.）开头，后续可以包含字母、数字、点（.）或下划线（_）。
  • 对象名区分大小写，例如myVar和myvar是两个不同的对象。
  • 避免使用R的保留字（如if、else、for等）作为对象名。
  • 对象名应具有描述性，便于理解其用途，例如age、height等。
  • 可以使用下划线（_）或驼峰命名法（如male_age、myVariable）来提高可读性.

函数

  • 函数是执行特定任务的代码块
  • 使用函数时，需键入函数名并在其后的括号中再提供相应的数据, 即函数的参数（argument）
  • R中有许多内置函数，也可以自定义函数。

常用内置函数示例：

die <- c(1, 2, 3, 4, 5, 6) # 创建一个名为die的对象，包括1到6的数值
mean(die) # 计算平均值
[1] 3.5
length(die) # 计算长度
[1] 6

函数参数

函数参数可以是原始数据、R对象、或其它函数的输出值。

round(mean(die), 2) # 计算平均值并保留两位小数
[1] 3.5

函数嵌套时，内层函数先执行，结果作为外层函数的参数。

当函数有多个参数时，可以使用位置参数（positional argument）或命名参数（named argument）来传参。

round(3.14159, 2) # 使用位置参数
[1] 3.14
round(digits = 2, x = 3.14159) # 使用命名参数
[1] 3.14

函数参数

args函数可以用来查看一个函数的参数列表和默认值。

args(round) # 查看round函数的参数列表
function (x, digits = 0, ...) 
NULL

这里显示digits已经被设置为0（默认值），意味着如果不提供digits参数，默认会将结果四舍五入到整数。

需要了解某一函数的具体用法，可以查看该函数的帮助文档，在控制台键入?函数名，例如?round，或者使用help(函数名)，例如help(round)。

自定义函数

基本语法如下：

function_name <- function(arg1, arg2 = default_value, ...) {
  # 函数体
  return(result)
}

例如：

# 定义一个函数，计算两个数的和
add <- function(x, y = 0) {
  result <- x + y
  return(result)
}
# 调用函数
add(5) # 只提供一个参数，y使用默认值0
[1] 5
add(5, 10) # 提供两个参数，覆盖默认值
[1] 15

原子型向量

R中的原子型向量（atomic vector）是由同一类型的元素组成的一维数组。

die <- c(1,2,3,4,5,6) # 可以将一组数据用c()函数组合成一个原子型向量
is.atomic(die) # 判断die是否是一个原子型向量
[1] TRUE
five <- 5 # 单个数值也是一个长度为1的原子型向量
is.atomic(five)
[1] TRUE

R中有六种基本的原子型向量，分别是双整型（double）、字符型（character）、逻辑型（logical）、整数型（integer）、复数型（complex）和原生型（raw）。

双整型向量

双整型向量用来存储普通的数值型数据，R中键入的任何一个数值都会默认以双整型存储。

num_v <- c(1, 2.3, -3, -100.4) # 创建一个数值向量
num_v
[1]    1.0    2.3   -3.0 -100.4
typeof(num_v) # 查看num_v的类型
[1] "double"

双整型常被称为数值型（numeric）。双整型来源于计算机科学中的双精度浮点数（double-precision floating-point number），它使用64位来存储一个数值。

整数型向量

整数型向量用来存储整数数据，在R中可以通过在数值后面添加L来创建一个整数型向量。

int_v <- c(1L, 2L, 3L, 4L, 5L) # 创建一个整数向量
int_v
[1] 1 2 3 4 5
typeof(int_v) # 查看int_v的类型
[1] "integer"

字符型向量

字符型向量用来存储文本数据:

text <- c("Hello", "World", "!", "2026") # 创建一个字符向量
text
[1] "Hello" "World" "!"     "2026" 
typeof(text) # 查看char_v的类型
[1] "character"

字符型向量中的每个元素称作一个字符串（string），可以是单词、句子或任何文本，用一对引号包围。

x <- "x"

注意避免将字符串和R对象混淆，上例中x是一个字符型向量，长度为1，储存的值是字符串"x"。

逻辑型向量

逻辑型向量存储布尔值（Boolean values），即TRUE和FALSE:

log_v <- c(TRUE, FALSE, T, F) # 创建一个逻辑向量
log_v
[1]  TRUE FALSE  TRUE FALSE
typeof(log_v) # 查看log_v的类型
[1] "logical"

比较算符（==、!=、>、<等）和逻辑算符（&、|、!等）

c(FALSE, FALSE, TRUE) & c(FALSE, TRUE, TRUE) 
[1] FALSE FALSE  TRUE
c(TRUE, TRUE, FALSE) | c(FALSE, TRUE, FALSE)
[1]  TRUE  TRUE FALSE
!c(TRUE, FALSE, TRUE)
[1] FALSE  TRUE FALSE

矩阵

矩阵（matrix）是二维数组，元素类型相同。可用matrix()创建矩阵。

m <- matrix(1:6, nrow = 2, ncol = 3) # 创建一个2行3列的矩阵
m
     [,1] [,2] [,3]
[1,]    1    3    5
[2,]    2    4    6

默认按照列优先（column-major order）填充矩阵。

设置byrow = TRUE，按行优先（row-major order）填充：

m_byrow <- matrix(1:6, nrow = 2, byrow = TRUE) # 按行优先填充矩阵
m_byrow
     [,1] [,2] [,3]
[1,]    1    2    3
[2,]    4    5    6

数组

array函数创建n纬数组，第一个参数是一个向量，dim参数指定了数组的维度。

ar <- array(c(11:14, 21:24, 31:34), dim = c(2, 2, 3)) # 创建一个2x2x3的数组
ar
, , 1

     [,1] [,2]
[1,]   11   13
[2,]   12   14

, , 2

     [,1] [,2]
[1,]   21   23
[2,]   22   24

, , 3

     [,1] [,2]
[1,]   31   33
[2,]   32   34

向量、矩阵和数组之间的联系

三者皆储存同类型数据，矩阵和数组比向量多了维度属性（attribute）。

vec <- 1:6; mat <- matrix(1:6, nrow = 2); arr <- array(1:6, dim = c(2, 3))
attributes(vec) # 向量没有属性
NULL
attributes(mat) # 矩阵有dim属性
$dim
[1] 2 3
attributes(arr) # 数组有dim属性
$dim
[1] 2 3
c(typeof(vec), typeof(mat), typeof(arr)) # 元素类型都是整型
[1] "integer" "integer" "integer"

因子

因子（factor）用于存储分类数据，比如性别、血型、教育水平等，可以使用factor()函数创建因子。

name <- c("Alice", "Bob", "Charlie", "David")
gender <- factor(c("Male", "Female", "Female", "Male")) # 创建一个因子
gender
[1] Male   Female Female Male  
Levels: Female Male

因子和字符型向量有什么区别？

因子

向factor函数传递一个原子型向量以生成因子，向量中的值会重新编码为一串整数值储存为一个整数型。

typeof(gender)
[1] "integer"

此外，因子还具有一个重要的属性：水平（levels），它存储了分类变量的所有可能取值。

levels(gender) # 查看gender因子的水平
[1] "Female" "Male"

因子还包含一个属性类（class），它告诉R这个对象是一个因子。

class(gender) # 查看gender因子的类
[1] "factor"

列表

列表（list）是一维有序集合，其中的元素是R对象，且可以是不同类型的对象。使用list()函数创建列表。

my_list <- list(name = "Alice", age = 30, scores = c(85, 90, 95)) # 创建一个列表
my_list
$name
[1] "Alice"

$age
[1] 30

$scores
[1] 85 90 95

列表中的每个元素都可以通过名称或位置访问：

my_list$name # 通过名称访问
[1] "Alice"
my_list[[2]] # 通过位置访问
[1] 30

数据框

数据框（data.frame）是表格数据结构，是数据分析中最为常用的数据结构。数据框的列可以是不同类型的数据。使用data.frame()函数创建数据框。

df <- data.frame(name = c("Alice", "Bob", "Charlie"), age = c(30, 25, 35), gender = factor(c("Female", "Male", "Male"))) # 创建一个数据框
df
     name age gender
1   Alice  30 Female
2     Bob  25   Male
3 Charlie  35   Male

向量索引和元素选取

R中可以使用索引来选取向量、矩阵、数组、列表和数据框中的元素。

向量索引常使用位置索引（整数）或逻辑索引（布尔值）：

vec <- c(10, 20, 30, 40, 50)
vec[1] # 位置索引，选取第一个元素
[1] 10
vec[c(2, 4)] # 位置索引，选取第二和第四个元素
[1] 20 40
vec[vec > 25] # 逻辑索引，选取大于25的元素
[1] 30 40 50
vec[c(1,1)] # 位置索引，选取第一个元素两次
[1] 10 10

位置索引可以是负数，表示排除对应位置的元素：

vec[-1] # 排除第一个元素
[1] 20 30 40 50
vec[-c(2, 4)] # 排除第二和第四个元素
[1] 10 30 50

矩阵索引和元素选取

矩阵和数组的索引：

m <- matrix(1:10, nrow = 2)
m[1, 2] # 选取第一行第二列的元素
[1] 3
m[, c(3, 5)] # 选取第三、五列的所有元素
     [,1] [,2]
[1,]    5    9
[2,]    6   10
m[-1, c(1, 4)] # 排除第一行，选取第一、四列的元素
[1] 2 8
m[m > 4] # 选取大于4的元素
[1]  5  6  7  8  9 10

数据框索引和元素选取

数据框的索引可以使用位置索引、列名索引或逻辑索引：

df <- data.frame(name = c("Alice", "Bob", "Charlie"), age = c(30, 25, 35), gender = factor(c("Female", "Male  ", "Male"))) # 创建一个数据框
df[1, ] # 选取第一行
   name age gender
1 Alice  30 Female
df[, "age"] # 选取age列
[1] 30 25 35

$符号是数据框和列表中特有的索引方式，用于选取列：

df$gender # 选取gender列
[1] Female Male   Male  
Levels: Female Male Male  
df[df$age > 30, ] # 选取age大于30的行
     name age gender
3 Charlie  35   Male

列表索引和元素选取

列表的索引可以使用位置索引、名称索引或逻辑索引：

my_list <- list(name = "Alice", age = 30, scores = c(85, 90, 95)) # 创建一个列表
my_list[["name"]] # 选取name元素
[1] "Alice"
my_list[[3]] # 选取第三个元素，即scores
[1] 85 90 95
my_list$scores # 选取scores元素的另一种方式
[1] 85 90 95
my_list[3]
$scores
[1] 85 90 95

[]和[[]]的区别：

  • []返回列表，即使只选一个元素，结果仍是一个列表。
  • [[]]返回元素本身，如果选取一个元素，结果就是该元素的值，而不是一个列表。
