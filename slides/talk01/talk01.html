R语言基础

R语言是什么？

R是一种主要用于统计分析和数据可视化的编程语言和环境。

R语言的特点：

  • 开源：免费使用，拥有庞大的社区支持。
  • 专为统计分析设计：提供了丰富的统计方法和工具，适合各种数据分析任务。
  • 优秀的可视化功能：如ggplot2等包提供了强大的数据可视化工具。
  • 丰富的包：有成千上万的包，涵盖各种工具，例如，机器学习、深度学习、生物信息学等领域。

R语言的安装

R语言的安装包括R本身和一个集成开发环境（IDE）,推荐使用RStudio作为IDE。

  1. 安装R语言：
    • 访问R项目官网下载并安装适合你操作系统的R版本。
  2. 安装RStudio：
    • 访问RStudio官网下载并安装RStudio Desktop版本。

Positron是Posit公司全新推出的IDE，如果你熟悉vs code，想要更好的AI支持，可以考虑安装Positron。

变量与赋值

变量：在R中，变量是用来存储数据的容器，可以是数值、字符、逻辑值等类型。

变量赋值：使用<-或=进行变量赋值。

x <- 10
y = 20

注意：虽然<-和=都可以用于赋值，但在R中，推荐使用<-进行变量赋值，以避免与函数参数中的=混淆。

变量命名规则

变量命名的注意事项：

  • 变量名必须以字母或点（.）开头，后续可以包含字母、数字、点（.）或下划线（_）。
  • 变量名区分大小写，例如myVar和myvar是两个不同的变量。
  • 避免使用R的保留字（如if、else、for等）作为变量名。
  • 变量名应具有描述性，便于理解其用途，例如age、height等。
  • 变量名中不应包含空格，可以使用下划线（_）或驼峰命名法（如myVariable）来提高可读性。

基础数据类型

R中的基础数据类型包括：

  • 浮点型（double）：用于存储数值数据，例如3.14、-2等。
  • 字符型（character）：用于存储文本数据，例如"Hello, World!"。
  • 逻辑型（logical）：用于存储布尔值，只有TRUE和FALSE两种取值。
  • 整数型（integer）：用于存储整数数据，例如1L、100L等。
  • 复数型（complex）：用于存储复数数据，例如1 + 2i。
  • 原生型（raw）：用于存储原始字节数据，基本接触不到。

数据结构

R中的常见数据结构包括：

  • 向量（vector）：同一类型元素的有序集合。
  • 矩阵（matrix）：二维数组，元素类型相同。
  • 数组（array）：多维数组，元素类型相同。
  • 数据框（data.frame）：表格数据结构，列可以是不同类型。
  • 列表（list）：可以包含不同类型的元素。
  • 因子（factor）：用于存储分类数据。

向量

向量（vector）：同一类型元素的有序集合。例如：

# 创建一个数值向量
num_v <- c(1, 2, 3, 4, 5)
num_v_1 <- 1:5
# 创建一个字符向量
char_v <- c("a", "b", "c", "d", "e")
# 创建一个逻辑向量
log_v <- c(TRUE, FALSE, TRUE, FALSE, TRUE)

向量化

R中的许多操作都是向量化的，这意味着它们可以直接作用于整个向量，而不需要对向量中的元素逐一操作。

# num_v中的每个元素都加10
num_v + 10
[1] 11 12 13 14 15
# char_v中的每个元素都转换为大写
toupper(char_v) 
[1] "A" "B" "C" "D" "E"
# log_v中的每个元素取反
!log_v
[1] FALSE  TRUE FALSE  TRUE FALSE
