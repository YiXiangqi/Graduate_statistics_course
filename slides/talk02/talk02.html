第二讲：函数与 tidyverse

本讲目标

  • 熟悉函数的基本用法与自定义函数
  • 掌握 tidyverse 的核心工作流
  • 能完成 4 类常见任务：
    1. 数据可视化（ggplot2）
    2. 数据转换（dplyr）
    3. 数据整理（tidyr）
    4. 数据导入（readr）

函数

函数

  • 函数是执行特定任务的代码块
  • 使用函数时，需键入函数名并在其后的括号中提供参数（argument）
  • R 中有许多内置函数，也可以自定义函数
die <- c(1, 2, 3, 4, 5, 6)
mean(die)
[1] 3.5
length(die)
[1] 6

函数参数

函数参数可以是原始数据、R 对象、或其它函数的输出值。

round(mean(die), 2)
[1] 3.5

函数嵌套时，内层函数先执行，结果作为外层函数参数。

round(3.14159, 2)
[1] 3.14
round(digits = 2, x = 3.14159)
[1] 3.14

查看函数参数

args() 可以查看函数参数列表和默认值。

args(round)
function (x, digits = 0, ...) 
NULL

需要了解某一函数细节，可用 ?round 或 help(round)。

自定义函数

基本语法：

function_name <- function(arg1, arg2 = default_value, ...) {
  # 函数体
  return(result)
}
add <- function(x, y = 0) {
  result <- x + y
  return(result)
}

add(5)
[1] 5
add(5, 10)
[1] 15

... 参数（dots）

... 用于接收不定数量参数。

paste_words <- function(...) {
  paste(..., sep = " ")
}

paste_words("R", "for", "data", "science")
[1] "R for data science"

作用域（scope）

函数内创建的对象默认是局部对象。

x <- 10

f <- function(x) {
  y <- x + 1
  y
}

f(10)
[1] 11
x
[1] 10

匿名函数与管道

匿名函数通常用于临时计算。

nums <- c(1, 2, 3, 4)

nums |>
  (\(x) x^2)()
[1]  1  4  9 16

从这一页开始，后续 tidyverse 代码都以 |> 管道为主。

tidyverse 概览

什么是 tidyverse？

tidyverse 是一组风格统一的数据科学包。

  • 统一的数据结构（tibble）
  • 统一的语法（动词 + 管道）
  • 强调“整洁数据”（tidy data）

核心包

  • ggplot2：数据可视化
  • dplyr：数据转换
  • tidyr：数据整理
  • readr：数据导入
  • tibble、stringr、forcats、purrr

1. 数据可视化（ggplot2）

语法框架

ggplot2 的核心思想：

\[ \text{plot} = \text{data} + \text{aesthetics} + \text{geoms} \]

最小结构：

ggplot(data = ..., aes(x = ..., y = ...)) +
  geom_...()

散点图（1）

ggplot(flights, aes(x = dep_delay, y = arr_delay))

散点图（2）

ggplot(flights, aes(x = dep_delay, y = arr_delay)) +
  geom_point()

散点图（3）

ggplot(flights, aes(x = dep_delay, y = arr_delay, color = origin)) +
  geom_point(alpha = 0.2) +
  labs(
    title = "出发延误与到达延误",
    x = "出发延误（分钟）",
    y = "到达延误（分钟）",
    color = "机场"
  )

直方图

ggplot(flights, aes(x = dep_delay)) +
  geom_histogram(binwidth = 10, fill = "steelblue", color = "white") +
  labs(
    title = "出发延误分布",
    x = "出发延误（分钟）",
    y = "频数"
  )

条形图

ggplot(flights, aes(x = carrier)) +
  geom_bar(fill = "tomato") +
  labs(
    title = "不同航空公司航班数量",
    x = "航空公司",
    y = "航班数量"
  )

箱线图

ggplot(flights, aes(x = origin, y = dep_delay, fill = origin)) +
  geom_boxplot(outlier.alpha = 0.2) +
  labs(
    title = "不同机场的出发延误分布",
    x = "机场",
    y = "出发延误（分钟）"
  )

分面（facet）

ggplot(flights, aes(x = dep_delay, y = arr_delay)) +
  geom_point(alpha = 0.15, color = "#2C7FB8") +
  facet_wrap(~ origin)

常用美化

ggplot(flights, aes(x = dep_delay)) +
  geom_histogram(binwidth = 10, fill = "#41B6C4", color = "white") +
  labs(title = "出发延误分布") +
  theme_minimal()

小结：ggplot2

  • 先确定数据和变量映射（aes()）
  • 再添加几何对象（geom_*()）
  • 最后补充标签、分面和主题

3. 数据整理（tidyr）

什么是 tidy data？

整洁数据的三个规则：

  • 每个变量一列
  • 每个观测一行
  • 每个单元格一个值
