函数

函数的功能

  • 接受输入参数（arguments）
  • 执行特定的计算或操作
  • 返回结果
die <- c(1, 2, 3, 4, 5, 6)
mean(die)
[1] 3.5
length(die)
[1] 6

函数的组成

  • 函数也是对象（object）
  • 函数由3部分组成：参数（arguments）、函数体（body）和环境（environment）

函数参数

  • 函数参数可以是原始数据、R 对象、或其它函数的输出值。
round(mean(die), 2)
[1] 3.5

函数嵌套时，内层函数先执行，结果作为外层函数参数。

函数参数

  • 参数传递时，可按照位置（positional）或名称（named）传递。
round(3.14159, 2)
[1] 3.14
round(digits = 2, x = 3.14159)
[1] 3.14

查看函数参数

  • args() 可以查看函数参数列表和默认值。
args(round)
function (x, digits = 0, ...) 
NULL
  • ... 参数用于接收不定数量参数。

需要了解某一函数细节，可用 ?round 或 help(round)。

自定义函数

基本语法：

function_name <- function(arg1, arg2 = default_value, ...) {
  # 函数体
  return(result)
}

示例：

add <- function(x, y = 0) {
  result <- x + y
  return(result) # 可以省略，R会自动返回最后一个表达式的值
}

add(5)
[1] 5
add(5, 10)
[1] 15

... 参数用法（dots）

c(1, 2, 2, 5, 6, 7)
[1] 1 2 2 5 6 7

... 用于接收不定数量参数。

paste_words <- function(...) {
  paste(..., sep = " ")
}

paste_words("R", "for", "data", "science")
[1] "R for data science"

作用域（scope）

函数内创建的对象默认是局部对象。

x <- 10

f <- function(x) {
  y <- x + 1
  y
}

f(10)
[1] 11
x
[1] 10

匿名函数

匿名函数通常用于临时计算。

nums <- c(1, 2, 3, 4)
(function(x) x^2)(nums)
[1]  1  4  9 16
(\(x) x^2)(nums)
[1]  1  4  9 16

tibble和data.frame

tibble(tbl_df)是对数据框（data.frame）的拓展：

df <- data.frame(x_10 = 1:20, `3_y` = letters[1:20]); class(df)
[1] "data.frame"
df_tibble <- tibble(x_10 = 1:20, `3_y` = letters[1:20]); class(df_tibble)
[1] "tbl_df"     "tbl"        "data.frame"

tibble核心理念是“少做事、多抱怨”,例如：

  • 不会偷偷改变量名或变量类型(names(df)vs.names(df_tibble))。
  • 不支持模糊匹配列名(比较df$x和df_tibble$x)。
  • 当引用不存在的变量时，会明确报错，而非悄悄继续。
  • 打印显示更友好。

管道符号

  • |> 是R 4.1.0引入的原生管道操作符，用于将一个对象传递给下一个函数作为第一个参数。

管道符号

  • |> 是R 4.1.0引入的原生管道操作符，用于将一个对象传递给下一个函数作为第一个参数。
  • x |> f() 等价于 f(x)， x |> f(y) |> g(z) 等价于 g(f(x, y), z)。
vec <- c(1.44, 2, 3, 4, 5.9)
vec |> mean()
[1] 3.268
vec |> mean() |> round(2)
[1] 3.27

%>%是magrittr包中的管道操作符，功能类似于 |>。 tidyverse依赖于magrittr，因此在使用tidyverse时也可以使用%>%。

filter() 筛选行

filter()根据列的取值筛选出行。第一参数是数据框，后续参数通常是逻辑表达式，返回满足条件行组成的新数据框。

flights |>
  filter(month == 1) # 筛选出所有起飞延误超过60分钟的航班

注意：=是赋值运算符，==才是比较运算符。

练习1：filter()使用

  • 筛选出1月1日的航班(month和day)
Code 
flights |>
  filter(month == 1, day == 1)
  • 筛选出1月和2月的航班
Code 
flights |> 
  filter(month == 1 | month == 2)
Code 
flights |>
  filter(month %in% c(1, 2))
  • 起飞延误，到达未延误航班（dep_delay 和 arr_delay）
Code 
flights |>
  filter(dep_delay > 0, arr_delay <= 0)

select() 选择列

select()根据列名选择列。

  • 根据列名选择列：
flights |>
  select(year, month, day, dep_delay, arr_delay)
  • 选择两列间的所有列：
flights |>
  select(year:arr_delay)
  • 选择特定列之外的所有列：
flights |>
  select(!c(year, month))
flights |>
  select(!year:dep_delay)

select() 进阶

  • 选择所有为字符型向量的列
flights |> 
  select(where(is.character))
  • 选择包含特定字符串的列
flights |>
  select(contains("delay"))
  • 选择特定字符开头的列
flights |>
  select(starts_with("dep"))

练习2：管道符号使用

  • 新列默认在最后一列位置，.after或.before参数调整。

flights |>
  mutate(
    gain = dep_delay - arr_delay,
    speed_per_min = distance / air_time,
    speed_per_hour = speed_per_min * 60,
    .keep = "used" 
  )
  • 修改列：将dep_delay转换为小时
flights |> 
  mutate(dep_delay = dep_delay / 60)

数据整理(Data tidying)

“幸福的家庭都是相似的，不幸的家庭各有各的不幸。”
— 列夫·托尔斯泰

“Tidy datasets are all alike, but every messy dataset is messy in its own way.”
— Hadley Wickham

什么是tidy data?

  1. 每个变量一列，每列一个变量
  2. 每个观测一行，每行一个观测
  3. 每个值一个单元格，每个单元格一个值 来源：R4DS by Hadley Wickham

tidyr包

tidyr包提供了一系列函数用于数据整理，核心函数包括：

  • pivot_longer()：宽数据转长数据
  • pivot_wider()：长数据转宽数据
  • separate()：拆分列
  • unite()：合并列
  • drop_na()：删除缺失值
  • replace_na()：替换缺失值
  • …

readr包

readr包提供了一系列函数用于数据读写，核心函数包括：

  • read_csv()：读取CSV文件
  • read_tsv()：读取制表符分隔的文件
  • read_delim()：读取任意分隔符的文件
  • read_table()：读取空格分隔的文件
  • write_csv()：写入CSV文件
  • write_rds()：写入RDS文件
  • …
