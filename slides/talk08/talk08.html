mgcv 包中的常用样条函数

薄板回归样条

薄板回归样条 (Thin plate regression splines, TPRS) 是 mgcv 包中默认的样条函数（bs = "tp"），官方文档（?smooth.terms）中:

“These are low rank isotropic smoothers of any number of covariates.”

  • low rank 指所用样条函数是薄板样条的低秩（简化）版本，需要更少的参数：
    • 通常不需要关心节点 (knots) 位置的选择, 会自动选择。
  • isotropic 指协变量坐标系的旋转不会改变平滑的结果。
    • gam(y ~ s(x1, x2))
    • x1 和 x2应该是在同一尺度上的变量。
    • 考虑了交互效应，但是不能将主效应和交互效应分开。
  • 给定 k，TPRS 通常是表现最好的样条函数。

三次回归样条

三次回归样条 (Cubic regression splines) 是:

  • s(..., bs = "cr", ...)
  • 基函数是分段三次多项式，分段由节点 (knots) 定义
  • 分段三次多项式在节点处连续，且节点处的一阶和二阶导数也连续
  • 默认节点位置由数据范围内的均匀分布的分位数确定，可指定节点位置。
  • 适用于单变量平滑
  • 不能直接处理多变量平滑，需要使用 tensor product smooths (te())

循环三次回归样条

循环三次回归样条 (cyclic cubic regression splines):

  • s(...,bs = “cc”, ...)
  • 在 CRS 的基础上额外要求在边界处函数值、一阶和二阶导数值相等
  • 适用于周期性数据

bs = "ts" 和 bs = "cs"

bs = "ts" ( TPRS with shrinkage) 和 bs = "cs" (CRS with shrinkage) 分别是是在薄板回归样条和三次回归样条的基础上：

  • 添加了对零空间的惩罚
  • 使得当平滑参数趋于无穷大时，函数会退缩到零。

模型选择 Model selection

零空间 Null space

对于标准 GAM：

  • GAM 在拟合时包含有惩罚项（常见的是二阶导数平方的积分），以防止过拟合。
  • 有些形式的函数会被惩罚，有些形式的函数不会被惩罚。
  • 不被惩罚的函数组成了零空间（Null space）
  • 随着 smoothing parameter (sp) 升高，被惩罚的函数形式会不断“退缩”（edf 下降），当“退缩”到零空间时就不会继续被惩罚了。
  • 即使 sp 变为无穷大，被惩罚的函数也不会“退缩”为 0。

AIC

  • AIC 是一种常用的模型选择标准，旨在平衡模型的拟合优度和复杂度。
  • AIC 经验法则：
    • \(\Delta AIC > 2\): 小差异
    • \(\Delta AIC > 4\): 中等差异
    • \(\Delta AIC > 10\): 明显差异
simu_df_gam_m3 <- gam(y ~ s(x1) + s(x2), method = "REML", data = simu_df)
simu_df_gam_m4 <- gam(y ~ s(x2) + s(x3), method = "REML", data = simu_df)

假设检验 Hypothesis testing

假设检验在 GAM 中很 tricky，建议阅读官方文档（?anova.gam）

  • 当只有一个模型时，anova.gam(model) 对每个参数项和平滑项进行检验，类似于 drop(1) 或者 Type III ANOVA
  • 当有多个模型时，
    • ()会进行模型比较，类似 anova() 函数的功能，可以指定检验方法（如卡方检验、F检验等）
    • 不要用该方法检验可以被惩罚为0的项
    • 可能出现结构更复杂模型的 edf 更小的情况，不适用。
