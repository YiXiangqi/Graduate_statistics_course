回顾：交互效应

什么是交互效应？

  • 交互效应（Interaction Effect）指两个或多个自变量（解释变量）共同作用时，对因变量（响应变量）的影响不等于它们独立效应的简单相加。

  • 换句话说，一个变量对结果的影响依赖于另一个变量的取值。

  • 拮抗作用（Antagonistic Effect）与 协同作用（Synergistic Effect）

分类变量间的交互效应

分类变量 × 分类变量：一个直观例子

  • 设有一个 2×2 的应用场景：教学方法（传统/互动） × 学生基础（较弱/较强）影响考试成绩。
  • 如果互动教学对基础较弱的学生帮助更大、对基础较强的学生帮助较小，那么教学方法的效果就会依赖于学生基础。
  • 这种“一个因素的效应取决于另一个因素”的现象，就是分类变量间交互效应的直观含义。
  • 下面的 4 行数据是示意性的组均值（illustrative grouped means），不是原始观测值；这里只是用来说明交互结构，不作推断解释。

如何识别分类变量间的交互效应

  • 汇总表
  • 点线图
教学方法 学生基础 平均成绩
传统 较弱 68
传统 较强 82
互动 较弱 78
互动 较强 84
  • 如果两条线大致平行，说明教学方法的影响在不同学生基础下较稳定。
  • 如果两条线不平行，说明教学方法的影响随学生基础而变化，也就是存在交互效应。
  • 因此，不平行的线条是交互效应的一个重要视觉信号。

在线性模型中表示分类变量间交互

interaction_lm <- lm(score ~ method * background, data = teaching_demo)
interaction_lm

Call:
lm(formula = score ~ method * background, data = teaching_demo)

Coefficients:
              (Intercept)                 method互动  
                       68                         10  
           background较强  method互动:background较强  
                       14                         -8
  • method 和 background 是两个主效应，分别刻画教学方法和学生基础的平均差异。
  • method:background 是交互项，用来描述两者联合作用是否偏离简单相加。
  • 在公式中，method * background 等价于 method + background + method:background。

分类变量与连续变量间的交互效应

penguins 数据集

lm()：分类变量\(\times\)连续变量

  • 情景1：不存在种间差异
penguins_lm_m0 <- lm(body_mass_g ~ flipper_length_mm, 
                     data = penguins)
  • 情景2：不同截距，相同斜率
Code 
penguins_lm_m1 <- lm(body_mass_g ~ flipper_length_mm + species, 
                     data = penguins)
  • 情景3：不同斜率，相同截距
Code 
penguins_lm_m2 <- lm(body_mass_g ~ flipper_length_mm:species, 
                     data = penguins)

penguins_lm_m3 <- lm(body_mass_g ~ flipper_length_mm + flipper_length_mm:species, 
                     data = penguins)
  • 情景4: 不同斜率，不同截距
Code 
penguins_lm_m4 <- lm(body_mass_g ~ flipper_length_mm*species, 
                     data = penguins)

metals 数据集

gam()：分类变量\(\times\)连续变量

  • 情景1：土壤类型间不存在差异
Hg_gam_m0 <- gam(Hg ~ s(Date), 
               data = metals, method = 'REML')
  • 情景2：不同截距，相同趋势（平滑函数）
Code 
Hg_gam_m1 <- gam(Hg ~ s(Date) + SoilType,
               data = metals, method = 'REML')
  • 情景3：相同截距，不同趋势（平滑函数）
Code 
Hg_gam_m2 <- gam(Hg ~ s(Date, by = SoilType),
               data = metals, method = 'REML')
  • 情景4：不同截距，不同趋势（平滑函数）
Code 
Hg_gam_m3 <- gam(Hg ~ s(Date, by = SoilType) + SoilType,
               data = metals, method = 'REML')

s()、te()和ti() 的区别

函数 主要作用 适用场景 关键说明
s(x, z) 对两个连续变量建立二维平滑曲面 两个变量尺度相近，想直接描述联合非线性效应 常用薄板样条等各向同性平滑，不拆分主效应与交互效应
te(x, z) 为多个连续变量构建张量积平滑 两个变量量纲不同，且希望直接建模完整平滑曲面 各维度可使用不同基函数，适合量纲差异明显的情形
ti(x, z) 构建“纯交互”平滑项 已经单独加入 s(x) 和 s(z) 主效应后，再加入交互效应 常与主效应项配合使用，避免与主效应重复
