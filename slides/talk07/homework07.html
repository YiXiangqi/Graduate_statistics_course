Section A：两因素方差分析与平方和类型

关键概念回顾

当响应变量是连续变量、解释变量是分类变量时，我们可以把方差分析写成线性模型的形式来理解。对于本题，species 和 sex 都是分类变量，因此可以把“企鹅体重在不同组之间是否有差异”写成一个两因素 ANOVA / 线性模型问题来分析。

同时要注意：当数据不是 perfectly balanced 时，ANOVA 表中每一项的平方和可能会依赖变量进入模型的顺序。因此，在解释 anova() 输出时，必须结合数据平衡性和 sums of squares 类型一起考虑。

ImportantQA.1

数据集：penguins_df（由 palmerpenguins::penguins 清洗得到）

  1. 使用两因素方差分析研究企鹅体重 body_mass_g 是否会因 species 和 sex 的不同而显著变化。
  2. 使用 aov() 或与之等价的线性模型形式，对模型 body_mass_g ~ species + sex 进行分析。
  3. 解读输出结果，并分别回答：
    • species 是否显著？
    • sex 是否显著？
    • 你的统计结论应该如何用自然语言表达？
ImportantQA.2

  1. 使用 count() 或 table() 检查 species 与 sex 的组合频数。

  2. 判断这个数据集在 QA.1 中是否是 perfectly balanced，并说明理由。

  3. 使用 lm() 和 anova() 重新分析 QA.1 的同一个模型：

    penguins_lm_a <- lm(body_mass_g ~ species + sex, data = penguins_df)
anova(penguins_lm_a)

  4. 交换解释变量顺序，重新拟合并比较结果：

    penguins_lm_b <- lm(body_mass_g ~ sex + species, data = penguins_df)
anova(penguins_lm_b)

  5. 比较两张 ANOVA 表。它们是否完全相同？如果不同，请解释为什么这种差异会出现。

ImportantQA.3
  1. anova.lm() 默认对应哪一种 sums of squares？
  2. 对当前这个分析问题来说，这是否是一个理想的选择？请说明理由。
  3. 如果不是，请使用更合适的方法重新分析（例如对这里的加性无交互模型 body_mass_g ~ species + sex 使用 car::Anova() 的 Type II sums of squares），并解释为什么它更合适。
  4. 比较默认 anova() 与 car::Anova() 的差异，说明你最终会依据哪一种分析给出结论。

Section B：smooth term p 值的零假设

关键概念回顾

使用 mgcv::gam() 拟合广义加性模型后，summary() 会在 “Approximate significance of smooth terms” 这一部分给出 smooth term 的检验结果。很多同学容易把这个 p 值误解为“是否显著偏离线性”，但这并不是本题想当然接受的解释。你需要用模拟来判断，这个 p 值真正对应的原假设是什么。

ImportantQB.1

请围绕下面的问题完成一个小型模拟实验：

  1. summary() 中 smooth term 的 p 值，原假设更接近下面哪一种？
    • A. 该变量对响应变量没有作用，平滑函数是零函数；
    • B. 该变量与响应变量之间的关系是线性的。
  2. 先模拟一组线性关系数据，例如 \[ y = 2x + 5 + \varepsilon , \] 然后拟合 gam(y ~ s(x))，报告 smooth term 的 edf 与 p 值，并解释这说明了什么。
  3. 再模拟一组明显非线性关系数据，例如 \[ y = x^2 + \varepsilon , \] 同样拟合 gam(y ~ s(x))，比较 edf 与 p 值。
  4. 基于两组模拟结果，回答：smooth term 的 p 值更像是在检验“没有效应”还是“关系为线性”？
  5. 请在结论中明确说明，为什么“smooth term 显著”并不等同于“已经证明关系一定是非线性的”。

Section C：HadCRUT4 温度异常的 GAM 分析

关键概念回顾

第七讲中，我们用 gtemp.csv 研究全球温度异常随年份变化的长期趋势。gam(Temperature ~ s(Year), data = gtemp) 提供了一个灵活的非参数趋势模型，但默认设置并不一定总是最合适，因此需要结合模型输出和诊断结果来判断。

ImportantQC.1

  1. 使用默认设置拟合下面的模型：

    gtemp_gam_default <- gam(Temperature ~ s(Year), data = gtemp)

  2. 解释 s() 中参数 k 与 bs 的含义。

  3. 解释 gam() 中参数 method 的含义。

  4. 查明这些参数在这里的默认值分别是什么。

ImportantQC.2
  1. 解读 summary(gtemp_gam_default) 的输出结果。
  2. 使用 gam.check(gtemp_gam_default) 对模型进行诊断。
  3. 根据诊断结果，判断默认 k 是否足够，并说明你的依据。
  4. 如果你认为默认 k 不够，请解释这可能导致什么问题。
ImportantQC.3
  1. 用更合适的设置重新拟合模型：
    • 使用 method = "REML"；
    • 使用 cubic regression spline，即 bs = "cr"；
    • 选择一个比默认值更合理的 k，并解释你的选择。
  2. 解读新模型的 summary() 输出。
  3. 比较默认模型与新模型在 edf、smooth term 检验结果和诊断输出上的差异。
  4. 结合统计结果与模型诊断，说明你最终更推荐哪一个模型设定，以及为什么。
