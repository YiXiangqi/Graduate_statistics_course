数学公式

Quarto 支持 LaTeX 语法的数学公式，行内公式用 $...$ 包裹，块级公式用 $$...$$ 包裹。

行内公式

源文件中：$y = \beta_0 + \beta_1 x$
渲染后：\(y = \beta_0 + \beta_1 x\)

块级公式

源文件中：

$$
\hat{\beta}_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2}
$$

渲染后： \[ \hat{\beta}_1 = \frac{\sum (x_i - \bar{x})(y_i - \bar{y})}{\sum (x_i - \bar{x})^2} \]

Part 2：线性回归模型中的残差

本节聚焦于一元线性回归模型中常用到的 3 种残差，在了解基本概念和计算公式的基础上，结合案例数据进行手动计算和比对，加深对不同类型残差的理解。

原始残差

如果没有特别强调，残差就是指原始残差（Raw Residual），也叫普通残差（Ordinary Residual）。对于第 \(i\) 个观测值，原始残差定义为观测值与回归拟合值的差： \[ e_i = y_i - \hat{y}_i \]

仍以palmerpenguins::penguins数据集为例，建立体重（body_mass_g）对鳍长（flipper_length_mm）的一元线性回归模型后，原始残差可以通过 residuals()函数获取。

penguins_lm_m0 <- lm(body_mass_g ~ flipper_length_mm, data = penguins)
raw_residuals <- residuals(penguins_lm_m0)

head(raw_residuals)
          1           2           3           5           6           7 
 537.743839  339.316007 -657.854091 -358.482958   -9.426259  412.743839

另外，也可以通过fitted()函数获取拟合值，结合观测值手动计算原始残差：

penguins_lm_m0_fitted <- fitted(penguins_lm_m0)
# 这里通过`penguins_lm_m0$model$body_mass_g`获取观测值，
# 而没有从原数据框中直接提取，是为了避免NA的影响。
raw_residuals_man <- penguins_lm_m0$model$body_mass_g - penguins_lm_m0_fitted

head(raw_residuals_man)
          1           2           3           5           6           7 
 537.743839  339.316007 -657.854091 -358.482958   -9.426259  412.743839

lm()函数返回的对象是一个列表，其中包括诸多关于模型的信息。

比较两种方法计算的原始残差是否相同：

sum(abs(raw_residuals - raw_residuals_man))
[1] 5.977104e-11

这里sum()和abs()用于求和和求绝对值。

标准化残差（Standardized Residual）

已知残差的期望和方差如下： \[ E(e_i) = 0, \quad var(e_i) = \sigma^2(1 - h_{ii}) \]

其中 \(\sigma^2\) 是误差项的方差，\(h_{ii} = \frac{1}{n} + \frac{(x_i - \bar{x})^2}{\sum_{j=1}^n (x_j - \bar{x})^2}\) 是第 \(i\) 个观测值的杠杆值。

为了消除杠杆值的影响，同时为了能够有效判断残差的大小，将原始残差进行标准化，得到标准化残差： \[ r_i = \frac{e_i}{\hat{\sigma} \sqrt{1 - h_{ii}}} \]

这里 \(\hat{\sigma}\) 为均方误差，是误差项方差的无偏估计，计算公式为： \[ \hat{\sigma}^2 = \frac{1}{n-2} \sum_{i=1}^n e_i^2 \]

标准化残差被有些人称为internally studentized residual。

标准化残差可以使用 rstandard() 函数获取：

standardized_residuals <- rstandard(penguins_lm_m0)
head(standardized_residuals)
          1           2           3           5           6           7 
 1.36991432  0.86329099 -1.67138210 -0.91097003 -0.02396391  1.05147406

手动计算标准化残差：

# R中，计算一般为向量化计算，即向量间对应位置的元素之间进行计算；
# 如果进行计算的两个向量的长度不相等，将会对长度较短的向量进行循环补齐，直到达到较长向量的长度。

n <- nrow(penguins_lm_m0$model) # 模型用到的观测数量

x <- penguins_lm_m0$model$flipper_length_mm

h_ii <- 1/n + (x - mean(x))^2 / sum((x - mean(x))^2)

sigma_hat <- sqrt(sum(raw_residuals^2) / (n - 2))

standardized_residuals_man <- raw_residuals / (sigma_hat * sqrt(1 - h_ii))

head(standardized_residuals_man)
          1           2           3           5           6           7 
 1.36991432  0.86329099 -1.67138210 -0.91097003 -0.02396391  1.05147406

比较手动计算的标准化残差与 rstandard() 的结果：

sum(abs(standardized_residuals - standardized_residuals_man))
[1] 2.220446e-16

学生化残差（Studentized Residual）

学生化残差又叫 externally studentized residual，定义如下： \[ t_i = \frac{e_i}{\hat{\sigma}_{(i)} \sqrt{1 - h_{ii}}} \]

这里\(\hat{\sigma}_{(i)}\)是去掉第 \(i\) 个观测值后重新拟合模型得到的均方误差。学生化残差可以使用 rstudent() 获取：

studentized_residuals <- rstudent(penguins_lm_m0)

studentized_residuals[1]
       1 
1.371689

Part 3：使用nlme包的varFunc系列函数构建异方差结构

这部分将使用模拟数据来练习如何使用nlme包的varFunc类函数定义不同误差项方差结构以处理异方差性问题。

示例

我们要生成一个数据框Homework04_dataset_0，其中包括因变量\(y\), 自变量\(x_1\)和\(x_2\)，满足以下关系： \[ y = \beta_0 + \beta_1x_1 + \beta_2x_2 + \varepsilon \] \(\beta_0,\beta_1,\beta_2\)分别为-10，5和7。同时，数据框中还有一个分类变量type, 包括两个水平type1和type2，对于误差项，我们令： \[ var(\varepsilon_{i}) = \sigma^2\ |x_{2i}|^{2\delta_{type_i}} \] 这里 i 表示第 i 个观测，\(type_i\) 表示第 i 个观测对应的type，type1对应的\(\delta\)为1.3，type2对应的\(\delta\)为1.8。下面的代码生成Homework02_dataset_0:

set.seed(10) #设置随机种子，生成的随机数可再现
Homework02_dataset_0 <-
  tibble(x1 = runif(200, 1, 10), # 在1到10范围内，生成200个随机数，服从均匀分布（uniform distribution）
         x2 = runif(200, 1, 10),
         y = -10 + x1*5 + x2*7,
         type = sample(factor(c("type1","type2")), size = 200, replace = T), # 生成长度为200的因子向量，随机从两个水平中挑选
         sigma = rnorm(200, mean = 0, sd = 1), # 生成200个随机数，服从正态分布
         noise = if_else(type == "type1", sigma * x2^1.3, sigma*x2^1.8),
         y_observed = y + noise)
